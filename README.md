## v1.4.5 更新（余额只认一处算法 + 删账户不再丢账）

上一版真机上发现「删掉一个账户，余额凭空变」，根因是账目挂在已删除的账户上、而余额是散在 SQL 里算的。
这一版把两件事一起收了：

- **余额算法收敛到 `BalanceMath` 一处**：收入 +、支出 −、转账双边一扣一加，`Repo` 的所有余额都走它。
  顺带修掉「自己转给自己会凭空少一笔」（旧 SQL 的 `CASE` 只扣不加）
- **删账户先迁账目**：点删除时如果名下还有 N 笔账目，会先让你选「转到哪个账户」，
  迁完再归档；不选就不给删（避免又造一批孤儿账目）
- **收红包/收转账修方向**：「[微信红包] 恭喜发财」原来被判成**支出**，现在补了 微信红包/收到红包/红包恭喜语 等收入词
- **余额口径全部有单测**：新增 `BalanceFlowTest` 20 条，断言的都是「哪个账户动了多少钱」——
  余额调整加钱/扣钱、收到转账、双边转账、信用卡还款、自己转自己、账户被删后的孤儿、迁移后总资产守恒

真机验证：`bal:8:250` → 微信 ¥250；`bal:8:20100` → ¥20,100；调回 ¥250 后**把三笔调整流水全删掉，余额仍是 ¥250**
（说明「删记录」和「动钱」是两件事）。单测 171 → **191 个**。

## v1.4.4 更新（银行卡↔微信零钱充值不再算成支出）

真机事故：从招商银行给微信零钱充值 ¥200 + ¥50，结果**微信余额反而少了 ¥250**。三个坑叠在一起：

- **没认出这是资金转移**：招行短信写的是「在【财付通-微信支付-微信零钱充值账户】发生快捷支付扣款」，
  转移词表里没有「零钱充值/充值账户」→ 被记成一笔**支出**（支出还虚增了）
- **账户被判成微信**：招行手机银行的包名是 `cmb.pb`，包名表里只有 `cmbchina`，认不出来 →
  退化成按关键词匹配，正文里的「微信」把账户抢走了，于是扣的是**微信**账户而不是银行卡
- **只扣单边**：就算记成转账，也只扣来源、不给目标加钱

现在：包名表补 `cmb`；转移词补 零钱充值/充值账户/转入零钱/提现到零钱/余额充值/转入微信/转入支付宝；
新增 `matchTransferTarget()` 认出「另一方」账户，记成**双边转账**（银行 −250、微信 +250，不计收支）。
真机验：重放同一条短信 → `资金转移：9 → 8（微信）`，微信 +1 分、招商银行 −1 分，两边都对。

单测 165 → **171 个**（新增 `TransferFlowTest` 6 条，用你真收到的那条招行原文当用例）。

## 一、先看这个：关于「自动记账」的真相

安卓出于安全，**不允许任何 App 直接读取微信 / 支付宝 / 银行的内部账单数据**。
钱迹、一木记账这些 App 的「自动记账」，本质上都是读**公开信息**。鲸鱼娘把四路来源全做了：

| 来源 | 实现 | 覆盖率 | 需要的授权 |
|---|---|---|---|
| **通知栏抓取**（主力） | `NotificationListenerService` 读「支付成功」类通知文本 | 微信/支付宝扫码、付款码、转账 ~85-95% | 通知使用权 |
| **银行短信** | `SMS_RECEIVED` 解析扣款短信 | 银行卡/信用卡几乎 100% | 短信权限（可选） |
| **无障碍增强**（默认关） | 读支付成功页面的屏幕文字补漏 | 补齐通知被折叠的漏抓 | 无障碍服务 |
| **账单导入**（兜底） | 导入微信/支付宝官方导出的 csv/zip | 100%（离线补历史） | 无 |

> 通知被折叠、App 静音、后台被系统杀掉就可能漏抓 —— 这时候「导入一次账单」就补齐了。
> 这也是所有同类 App 的真实能力边界，鲸鱼娘不会骗你说 100% 全自动。

**落地流程**：抓到 → 解析（金额/方向/商户/账户/分类）→ 算置信度
→ ≥ 阈值（默认 80%）**自动入账**（并给一条可撤销的静默通知）
→ 否则推一条通知问你「确认入账 / 忽略」，或进 App 的「待确认」列表一键改分类。

## 七、常见问题

**Q：付完款没抓到？**
A：① 权限向导里第 1 项是否真的开了；② 微信/支付宝的通知是否被系统折叠成「静默通知」（设置里把它们的通知改成「重要/横幅」）；③ 去「自动记账 → 最近抓取记录」看有没有抓到但方向/金额解析错了，可加自定义规则；④ 最后手段：导入账单。

**Q：抓到了一笔但不是支付（比如聊天里的转账）？**
A：进「待确认」点「✕ 忽略」；这类文本置信度低，不会自动入账。也可以在「自动记账规则」里加一条关键词规则收紧。

**Q：换手机怎么迁移？**
A：旧机「数据导入导出 → 创建加密备份」→ 分享到新机 → 新机「从备份恢复」。

**Q：能上应用商店吗？**
A：短信权限和通知监听在 Google Play / 国内商店都属于敏感权限，需要额外资质与说明。自用侧载完全没问题。
