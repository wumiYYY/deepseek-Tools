## 一、先看这个：关于「自动记账」的真相

安卓出于安全，**不允许任何 App 直接读取微信 / 支付宝 / 银行的内部账单数据**。
钱迹、一木记账这些 App 的「自动记账」，本质上都是读**公开信息**。鲸鱼娘把四路来源全做了：

| 来源 | 实现 | 覆盖率 | 需要的授权 |
|---|---|---|---|
| **通知栏抓取**（主力） | `NotificationListenerService` 读「支付成功」类通知文本 | 微信/支付宝扫码、付款码、转账 ~85-95% | 通知使用权 |
| **银行短信** | `SMS_RECEIVED` 解析扣款短信 | 银行卡/信用卡几乎 100% | 短信权限（可选） |
| **无障碍增强**（默认关） | 读支付成功页面的屏幕文字补漏 | 补齐通知被折叠的漏抓 | 无障碍服务 |
| **账单导入**（兜底） | 导入微信/支付宝官方导出的 csv/zip | 100%（离线补历史） | 无 |

> 通知被折叠、App 静音、后台被系统杀掉就可能漏抓 —— 这时候「导入一次账单」就补齐了。
> 这也是所有同类 App 的真实能力边界，鲸鱼娘不会骗你说 100% 全自动。

**落地流程**：抓到 → 解析（金额/方向/商户/账户/分类）→ 算置信度
→ ≥ 阈值（默认 80%）**自动入账**（并给一条可撤销的静默通知）
→ 否则推一条通知问你「确认入账 / 忽略」，或进 App 的「待确认」列表一键改分类。

## 二、安装

本仓库**不包含 APK**（`.gitignore` 已排除 `dist/`、`*.apk`），有两种方式拿到安装包：

```powershell
# 方式一：自己打（首次需先跑 .\scripts\setup-toolchain.ps1 准备工具链）
.\scripts\release.ps1
# → dist\1.2.2\ 下产出：鲸鱼娘金库-v1.2.2.apk（约 24.5 MB）+ SHA256SUMS.txt + 使用说明.txt/.md + 发布包.zip
```

方式二：向发布者索取 `dist/<版本>/` **整个目录**——里面三样东西要一起发：APK、`SHA256SUMS.txt`（校验用）、`使用说明.txt`（给使用者看）。

👉 **使用者请看 [docs/用户指引.md](docs/用户指引.md)**（= 随包的「使用说明」）：能装的前提、怎么开权限、30 秒自检、常见问题、换机备份。

安装步骤：

1. 把 APK 发到手机（微信/QQ 传文件、数据线拷贝、网盘都行）；
2. 点开安装，若提示「禁止安装未知来源应用」，按提示允许一次即可；
3. 首次打开按引导开权限（见下一节），然后去微信付一笔 0.01 元试试 —— 通知栏会弹出「🐳 抓到一笔支出」，点「确认入账」就完成了第一笔记账。

系统要求：**Android 8.0（API 26）及以上**，**arm64-v8a**（APK 只打了 arm64，模拟器 x86_64 装不了/OCR 不可用）。安装后占用约 24.5MB。

## 四、功能清单

**记账**
- 多账本（日常/装修/旅行…），顶部一键切换
- 支出 / 收入 / 转账，二级分类体系（24 个支出 + 9 个收入预置分类，可自定义名称、emoji、颜色、识别关键词）
- 大数字键盘 + 一句话备注 + 日期选择 + 标签 + 报销标记 + 拍照附票据
- 明细列表（按天分组、日合计）/ 月历热力视图（哪天花得多一眼看出）
- 搜索（备注/商户/标签）、编辑、删除

**自动记账**
- 四路抓取（通知 / 短信 / 无障碍 / 账单导入）
- 置信度打分 + 阈值自动入账 + 待确认队列 + 通知栏「确认/忽略/撤销」
- 商户记忆：同一商户下次自动归类
- 自定义规则：包名 + 关键词 + 金额正则 → 强制指定方向/分类/账户
- 抓取记录全量留档（通知原文可回看，方便你调规则）

**报表**
- 本月收支结余、笔数、日均、最大单笔
- 分类环形图 + 分类排行条
- 近 6 个月支出趋势
- 收入来源分析、标签花费排行
- 「鲸鱼娘月报」AI 点评（可选）

**计划**
- 月度总预算 + 分类预算 + 进度环 + 超支通知
- 储蓄目标（旅行基金之类），进度条 + 一键存入
- 借贷管理（应收/应付），一键结清

**周期账单**：房租、订阅、工资，到日子自动生成账目（可关自动只提醒）

**快捷入口**
- 桌面小组件（本月支出 + 今日 + 一键记一笔）
- 悬浮球（🐳 常驻，点一下记一笔）
- 桌面长按快捷方式（记一笔 / 语音记账）
- 每日记账提醒 + 预算超支提醒

**AI（可选，自填 Key）**
- 一句话记账：「昨天午饭 25 微信」
- 通知账单智能分类
- 月度消费点评
- 不填 Key 全部走本地规则，完全离线

**数据**
- 微信/支付宝官方账单导入（自动识别 UTF-8 / GBK 编码、自动去重）
- CSV 导出（Excel 直接打开）
- AES-GCM 加密备份 / 恢复（自己设密码，整库一个文件）

## 五、开发与构建

工具链全部收在 `.toolchain/`（JDK 17 + Android SDK 35 + Gradle 8.9），不污染系统环境。

```powershell
# 首次准备（下载 JDK / SDK / Gradle，约 1.5GB）
.\scripts\setup-toolchain.ps1

# 编译 debug
.\scripts\build.ps1 -Task assembleDebug

# 打签名 release APK → app\build\outputs\apk\release\
.\scripts\build.ps1 -Task assembleRelease

# 跑解析引擎单测（不需要手机）
.\scripts\build.ps1 -Task ":app:testDebugUnitTest"
```

签名密钥：`keystore/jingyuniang-release.jks`（别名 `jingyuniang`）。**keystore 与口令都不在仓库里**：
口令放在本机 `local.properties` 的 `WHALE_STORE_PASSWORD` / `WHALE_KEY_PASSWORD` / `WHALE_KEY_ALIAS`（也可用同名环境变量），
`keystore/`、`*.jks` 已被 `.gitignore` 排除。**升级安装必须用同一个 keystore**，否则会提示「签名冲突，需先卸载」；keystore 丢失 = 以后无法覆盖升级（详见 `docs/RELEASE.md` §5）。

## 六、隐私
- 账目、抓取到的通知原文、票据照片：**只在本机** SQLite + 私有目录；
- 没有账号系统、没有上报、没有广告与统计 SDK；

- 备份文件用你自己的密码加密（PBKDF2 12 万次 + AES-GCM），开发者也无法解开。

## 七、常见问题

**Q：付完款没抓到？**
A：① 权限向导里第 1 项是否真的开了；② 微信/支付宝的通知是否被系统折叠成「静默通知」（设置里把它们的通知改成「重要/横幅」）；③ 去「自动记账 → 最近抓取记录」看有没有抓到但方向/金额解析错了，可加自定义规则；④ 最后手段：导入账单。

**Q：抓到了一笔但不是支付（比如聊天里的转账）？**
A：进「待确认」点「✕ 忽略」；这类文本置信度低，不会自动入账。也可以在「自动记账规则」里加一条关键词规则收紧。

**Q：换手机怎么迁移？**
A：旧机「数据导入导出 → 创建加密备份」→ 分享到新机 → 新机「从备份恢复」。

**Q：能上应用商店吗？**
A：短信权限和通知监听在 Google Play / 国内商店都属于敏感权限，需要额外资质与说明。自用侧载完全没问题。

修复过的真实问题（都是评测机上跑出来才发现的）：
- `LocalDate.ofInstant` 是 API 33 API，minSdk 26 上启动即崩 → 改为 `atZone().toLocalDate()`；
- 「余额 1,234.56」被误当消费金额 → 重写金额打分（付费动词 +8 / 尾随「元」+5 / 余额·额度 -20）；

- edge-to-edge 在部分 ROM 上窗口高度与 insets 不一致，底部被裁掉 → 改为让装饰视图贴合窗口；
- 银行短信把「10月22日12:30」当商户 → 增加日期/卡号噪声过滤；
- 千分位金额在未加引号的 csv 里被逗号切开 → 导入时自动合并金额分组。

已知限制（诚实说明）：
- 通知被系统折叠 / App 关闭通知 / 后台被杀时可能漏抓，用「账单导入」兜底；

- 无障碍增强在部分 ROM 上会被系统回收，重开即可；
